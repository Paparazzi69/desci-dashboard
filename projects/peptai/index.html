// EVERY OTHER SECTION IS THE PITCH. THIS ONE IS THE HEDGE. READ IT TWICE.

// R-01 · LAB DATA
No independent wet-lab data yet. Every gate decision to date is computational. OX2R-004 has not been synthesised and tested in a real lab as of latest update.
// R-02 · GATE THRESHOLDS
Gate thresholds are not pre-registered. PASS/FAIL criteria are visible per-decision but not published as a single specification. The bar can move.
// R-03 · PARTNER DISCLOSURE
Adaptyv integration is disclosed by PeptAI only. Adaptyv has not independently announced the partnership on its own channels as of latest check.
// R-04 · PRE-IND SCOPE
Pre-IND is a marketing document, not a regulatory filing. OX2R-004 is years and multiple Phase trials away from any clinic. Treat the term accordingly.
